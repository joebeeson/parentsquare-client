# Security policy

## Reporting a vulnerability

Please use GitHub's private security advisory flow for this repository:

<https://github.com/joebeeson/parentsquare-client/security/advisories/new>

Do not include ParentSquare credentials, cookies, post bodies, attachments, or
private calendar URLs in an issue or pull request.

The project is an unofficial client for an undocumented web interface. Reports
about account restrictions or changed upstream behavior are welcome, but keep
account-specific evidence synthetic or redacted.
